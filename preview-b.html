02 / THE SKILL

从人物到笔触，
都有章法。

anime-lineart-director 把一句人物需求翻译成可执行的画面决策：谁在画面里、正在发生什么、线条往哪里走、哪里应该密、哪里必须留白。

A

人物结构

先锁定身份、景别、头肩与手部连接，让角色在乱线中仍然清楚。

B

笔触密度

结构主线、方向排线与少量寻找重描各司其职，避免全画面平均铺线。

C

关系与动作

明确多人位置、视线、接触和支撑关系，也能把动作压进一条主轴。

D

系列控制

同母稿只改变一个变量，或在共同视觉 DNA 下建立有差异的角色组图。

Skill 负责组织创作决策与提示词；实际出图依赖你使用环境中的图像生成能力。

03 / HOW TO USE

一句想法，变成一张
有秩序的草图。

不需要记参数表。安装 Skill 后，像委托一位画面导演一样说出你的想法。

01

安装 Skill

从 GitHub 获取 anime-lineart-director，放进工作环境的 skills 目录（例如 ~/.claude/skills/）。

02

描述人物与事件

例如：“画中野三玖扶着耳机，安静地看向镜头，用深靛蓝乱线速写。”

03

让它导演或直接出图

要提示词就说“给我提示词”；环境支持图像生成时，也可以明确说“直接出图”。
